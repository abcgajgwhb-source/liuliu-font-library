# liuliu-font-library

Figma 字体快速查询：中文字体分类、名称复制与下载入口。

## 功能

- 中文字体分类及名称搜索
- 复制已核验的 Figma 字体名称
- 跳转至设计稿中提供的下载入口
- 响应式布局

## 部署

静态 HTML、CSS、JavaScript，无需安装依赖或构建。GitHub Pages 使用 main 分支根目录，.nojekyll 用于直接发布静态文件。

## 当前数据与视觉限制

收录 164 条字体记录，62 条已核验详细信息，102 条下载入口和 Figma 名称待补充。缺失信息对应操作已禁用。中文之外的顶层栏目尚未填充。原设计背景和真实字体预览资源尚未恢复，目前使用纯色背景与系统字体回退。
